# Noryn — téléchargements

Noryn est un assistant vocal personnel. Application web : https://noryn-jhbf.onrender.com/

| Appareil | Fichier |
|---|---|
| PC (Windows) | [noryn.exe](noryn.exe) |
| Android | [noryn.apk](noryn.apk) |

## Installer sur Android
1. Télécharge `noryn.apk` sur ton téléphone.
2. Ouvre le fichier et autorise « Installer des applis inconnues » si Android le demande.

## Installer sur PC
1. Télécharge `noryn.exe` et lance-le.
2. Si Windows affiche « Windows a protégé votre PC » : « Informations complémentaires » puis « Exécuter quand même » (le fichier n'est pas signé).

Les deux applis ouvrent Noryn en plein écran ; tes conversations suivent ton compte Noryn.
